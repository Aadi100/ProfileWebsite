# Engr. Abdul Hadi — Engineering Portfolio

A modern, high-performance portfolio website built with **React**, **Vite**, and **Lucide Icons** showcasing the full-stack, systems, and IoT middleware engineering work of **Engr. Abdul Hadi (Aadi)**.

## 🛠️ Tech Stack & Architecture
- **Framework:** React 18 / 19
- **Bundler:** Vite
- **Icons:** Lucide React
- **Animations & FX:** Canvas Confetti, CSS Glassmorphism, Dynamic Radial Cyber Grid
- **Design System:** Custom Dark Cyber-Engineering UI (`#07090e`, glowing Emerald `#10b981` & Cyan `#06b6d4` accents)

## 💻 Development & Deployment Commands

### 1. Start Local Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized production bundle in the `dist/` folder.
